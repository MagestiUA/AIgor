# AIgor (Ігорь) — інструкція для тестувальників

Файл `Igor.exe` (зі сторінки [Releases](https://github.com/MagestiUA/AIgor/releases/latest)) — це все, що потрібно: Python, Node та інше встановлювати не треба.

## Перший запуск
1. Запустіть `Igor.exe` (перший старт трохи довший — файл розпаковується; Windows SmartScreen може
   попросити підтвердження: «Докладніше → Все одно виконати»).
2. Відкрийте **Налаштування** (шестерня внизу ліворуч) → «Підключення до LLM»:
   - оберіть **Сервер (OpenAI API)**;
   - вкажіть **адресу**, **порт**, свій **API-ключ** (модель можна лишити порожньою — підтягнеться сама);
   - натисніть **Перевірити**, потім **Зберегти**.
3. **Чат** — розмова та аналіз; **Код** — агент працює з вашою текою проєкту (вкажіть теку в полі внизу).

Перед роботою з важливим кодом зробіть `git commit`: Ігорь може змінювати файли у вибраній теці.

## Якщо щось зламалось — пришліть діагностику
Налаштування → **Діагностика**: збере логи в один архів (відкриється тека
`%USERPROFILE%\.local-code-agent\diagnostics\`). API-ключ і вміст ваших чатів/файлів у нього **не** потрапляють.
Надішліть архів разом з коротким описом: що робили, що очікували, що сталось, номер версії (права панель → «Версія»).

Логи також лежать у `%USERPROFILE%\.local-code-agent\logs\`:
`igor.log` (робота агента), `igor-launcher.log` (запуск), `igor-server.log` (помилки сервера). Ротація: до 2 МБ × 5.

## Корисно знати
- Права панель показує, що займає контекст моделі, з якими теками працює чат і які файли змінено (git).
- Коли Ігорь стискає контекст розмови, він пише про це в чаті.
- Дані (чати, налаштування) зберігаються в `%USERPROFILE%\.local-code-agent\`.
